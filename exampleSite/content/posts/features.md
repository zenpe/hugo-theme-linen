Hugo Linen is a Hugo port and adaptation of [hexo-theme-linen](https://github.com/LynanBreeze/hexo-theme-linen), originally created by LynanBreeze. This demo shows the Hugo implementation, including the theme-specific layouts, shortcodes, image behavior, and site configuration.

## Content and layout

| Feature | Demo |
| --- | --- |
| Homepage highlighted posts | [Highlighted posts](/highlighted-posts/) |
| Latest post list | Homepage latest section |
| Cover and thumbnail images | [Front matter reference](/front-matter/) |
| Archives, categories, tags, and series | [Archives](/archives/) |
| Table of contents | This page and long guide pages |
| Raw Markdown panel | Pages with `appendRawMarkdown: true` |

Start with [Getting started](/getting-started/), then continue with [Configuration guide](/configuration-guide/) and [Front matter reference](/front-matter/). The example site keeps all demo content under `exampleSite/content/posts/` so each feature can be inspected as a normal Hugo post.
